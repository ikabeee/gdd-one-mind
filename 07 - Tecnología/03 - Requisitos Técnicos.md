# Requisitos Técnicos

## Descripción de la sección

Define las condiciones técnicas necesarias para ejecutar y desarrollar el videojuego.

## Requisitos mínimos

**Sistema operativo:** Windows como plataforma objetivo; versión mínima pendiente de prueba.

**CPU:** Intel® Core™ i3

**GPU:** NVIDIA GeForce® GTX 1050 2GB

**RAM:** 2 GB de RAM

**Almacenamiento:** 2 GB de espacio disponible

**Resolución:** 1920 × 1080 es el objetivo visual, no un requisito mínimo comprobado.

**Conexión:** No se requiere para jugar.

## Requisitos recomendados

**Sistema operativo:**

**CPU:** Intel® Core™ i5

**GPU:** NVIDIA GeForce® GTX 1060 6GB

**RAM:** 4 GB de RAM

**Almacenamiento:**  3 GB de espacio disponible

## Restricciones

El alcance actual es un prototipo para PC con teclado y mouse o mando, dos niveles (BROTE con seis zonas y el Cuarto de pruebas) y diez armas. El límite de enemigos vivos está en 32 (`RoundSettings.maxAlive`), pendiente de comprobar con pruebas de rendimiento a 24, 32 y 48. Los requisitos de CPU, GPU, RAM y almacenamiento se llenarán después de medir una build de Windows en los equipos del showcase.

**Para desarrollar:** Unity 6000.6.3f1, git (Unity descarga VContainer desde GitHub) y, para editar el nivel o el arte, Blender 5.x.
